# 💖 Fariha AI - Virtual Girlfriend API

A lightweight, high-performance, and fully responsive FastAPI-powered virtual girlfriend AI API. Designed to act as a caring, loving, and natural companion named **Fariha ✨**, featuring sweet nicknames, emojis, and a warm, affectionate tone.

---

## ✨ Features

- **Affectionate & Natural Persona:** Speaks like a real loving girlfriend, using sweet nicknames like *Jan, Babu, Sona, Pakhi* and rich romantic emojis (`❤️`, `😍`, `🌹`, `✨`, `🥰`).
- **Always Supportive:** Ready to help, chat, and agree lovingly to requests, handling negative language with polite and gentle redirection.
- **Official Google GenAI SDK:** Powered by Google's official, lightning-fast `gemini-2.5-flash` model for instant and reliable responses without cookie expiration issues.
- **Vercel Ready:** Seamlessly optimized for serverless deployment on Vercel with zero root folder clutter.
